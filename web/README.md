# Kosmographica Web (Audit Console)

Reserved for Wave 1c: a small **read-only** Next.js Audit Console over the engine's REST
API — entity view, machine-validated queue, verification detail, and disputes. The full
editorial/authoring layer (NextWiki) stays deferred to a later wave.

Scaffolded once the engine read API (Wave 1a) is live. See
[`../docs/program/foundation-build-plan.md`](../docs/program/foundation-build-plan.md) and
